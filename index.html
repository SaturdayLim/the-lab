Engine

FlavorGraph — 6,600+ ingredient nodes embedded in 300 dimensions, 123k weighted pairing edges. Trained on 1M+ recipes and 1,500 flavour molecules. Park et al., Scientific Reports 2021.

Stack

Plain HTML / CSS / JS. No framework, no build step. Hosted on Vercel; auto-deploys on push to main. Design tokens shared by both apps.

Score guide

90–100 = well-tested, high-confidence pairings.
70–89 = interesting — worth exploring.
Below 70 = creative risk. Lower the threshold to see them.
